# Aeloria · 悬浮之境

一个《阿凡达》风格的浏览器 3D 飞行竞速世界（Three.js + Vite）。乘上伊卡兰，穿越漂浮的群山与环形光环赛道，在飞行途中迎战突如其来的雷暴。

所有模型、贴图和音效都在运行时程序化生成，项目里没有任何外部美术或音频资源。

## 运行

```bash
npm install
npm run dev
```

打开 <http://localhost:5173>。打包用 `npm run build`，产物在 `dist/`（使用相对路径，可直接部署到静态托管）。

需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 新版）。

## 玩法

- **开始竞速**：与 4 位纳美对手同场比赛，3 圈，按顺序穿过 28 个光环，金色光环是下一个目标。屏幕边缘的金色箭头和小地图会指引方向。最佳成绩保存在本地。
- **自由飞行**：没有计时，随意探索。
- 每穿过一个光环会回复灵能并获得少量加速。
- **AI 对手**：拉鲁（橙）、塞瑞（紫）、妮卡（绿）、托卡（白），各有不同的基础速度、冲刺频率和飞行风格。
  左上角是实时排名和与你的距离差，对手头顶有名字和名次标签。对手同样会被强风吹偏，被闪电劈中也会失速。
  它们带有轻度的橡皮筋平衡（领先太多会稍慢、落后太多会追赶），所以比赛始终咬得很紧。和对手相撞会被弹开并损失一点速度。
  菜单里可以选择对手难度（简单 / 普通 / 困难）；在主菜单和自由飞行中，它们会陪你一起巡航。
- **风暴**：平静 → 预警 → 雷暴 → 消散，循环往复。雷暴期间有强风推挤、乱流颠簸、暴雨和闪电。
  出现紫色光柱时表示**雷电已锁定你**（有时锁定的是对手），大约 1 秒后落雷，赶紧转向或爬升躲开，被击中会短暂失控并大幅减速。
- 撞上山体或碎石会减速；云海之下是深渊，飞得太低会被推回去。

## 操作

| 操作 | 按键 |
| --- | --- |
| 转向 / 俯仰 | 鼠标（指针锁定）· `W A S D` · 方向键 · 手柄左摇杆（`W` 是抬头） |
| 振翅加速 | `空格` · 鼠标左键 · 手柄 A |
| 灵能冲刺 | `Shift` · 鼠标右键 · 手柄 RT |
| 昼夜切换 | `N`（夜晚时生物荧光植物、灵魂之树和圣树种子会亮起来） |
| 召唤风暴 | `T` |
| 切换视角 | `C`（追随 / 远景 / 近身） |
| 静音 | `M` |
| 暂停 | `Esc` / `P` |
| 重新开始 | `R` |

菜单里可以切换画质（泛光开关）、反转 Y 轴、调节鼠标灵敏度，以及选择对手难度。

## 世界里有什么

- **92 座悬浮山**：哈利路亚山式的剖面经过噪声扰动，表面有岩层、苔藓和草地着色；山顶长着潘多拉树林，山沿垂下藤蔓，山壁上分布着生物荧光点，17 道瀑布从山顶倾泻进虚空。
- **灵魂之树**：坐落在中央巨山顶上，枝干相互缠绕，挂着 2600 条随风摇曳的发光丝绦。
- **420 块漂浮碎石**、环绕山腰的云团，以及脚下无尽的云海。
- **天空**：动态云层、星空与星云，还有一颗巨大的带状气态行星和两颗卫星。
- **伊卡兰坐骑与纳美骑手**：带关节的双段翅膀会振翅、滑翔和俯冲收翼；高速飞行时翼尖拖出尾迹。
- **程序化音频**：风声会随速度变化，还有雨声、氛围长音、振翅声、光环提示音、远近不同的雷声和阵风呼啸。

## 代码结构

```
src/
  main.js            游戏主循环、状态机（菜单 / 倒计时 / 飞行 / 暂停 / 结算）
  rivals.js          AI 对手：沿赛道飞行、橡皮筋平衡、冲刺、排名
  player.js          飞行物理（推力 / 阻力 / 重力 / 风）、碰撞响应、动画、尾迹
  ikran.js           伊卡兰与骑手的程序化模型和贴图
  track.js           闭合样条赛道、光环、引导光点、穿环检测
  storm.js           风暴循环、风与阵风、雨、闪电锁定与落雷
  cameraRig.js       第三人称追随相机
  hud.js             HUD、光环指示器、小地图
  audio.js           WebAudio 程序化音效
  input.js           键盘 / 鼠标 / 手柄输入
  particles.js       粒子爆发
  world/
    atmosphere.js    天空、行星、昼夜与风暴配色、雾和灯光
    mountains.js     悬浮山生成、植被、瀑布、碎石、碰撞
    soulTree.js      灵魂之树
    ambient.js       云海、云团、圣树种子
  utils/             噪声与数学工具
  shaders/           GLSL 噪声
```

世界使用固定随机种子生成，所以每次打开都是同一个 Aeloria。想换一个世界，修改 `main.js` 里的 `mulberry32(0xae10a1)` 即可。
